# NutriCart

Smart Grocery Shopping for Healthier Living

## Overview

NutriCart is an AI-powered nutrition and grocery shopping platform that helps individuals and families make healthier food choices while staying within budget.

By combining personalized nutrition recommendations, meal planning, grocery list generation, and smart shopping insights, NutriCart transforms the way people shop for food.

Whether you're trying to lose weight, eat healthier, manage dietary restrictions, save money, or plan meals efficiently, NutriCart provides intelligent guidance every step of the way.

## Installation

```bash
git clone https://github.com/yourusername/nutricart.git

cd nutricart

npm install

npm run dev
```

Open your browser:

```bash
http://localhost:3000
```

## Environment Variables

Create a `.env.local` file:

```env
OPENAI_API_KEY=your_api_key

DATABASE_URL=your_database_url

NUTRITION_API_KEY=your_nutrition_api_key

NEXTAUTH_SECRET=your_secret_key
```
